# Project preview pictures

Used by the hover preview in "Featured Projects". Until a picture exists, the site shows a generated placeholder.

## One picture
Name it after the project: `dole-kiosk.png`

## Several pictures
Number them from 1: `oshc-learning-academy-1.jpg`, `oshc-learning-academy-2.jpg`, `oshc-learning-academy-3.jpg` ...
(up to 8; the pictures change automatically on hover, and the cursor / arrow keys can flip through them)

Formats: `.webp`, `.png`, `.jpg`, `.jpeg`. Landscape 16:9 is best (the DOLE Kiosk uses a portrait screen).
