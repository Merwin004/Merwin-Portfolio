## ✨ Features

- 🎨 **Dark Mode Design** — Deep indigo/violet/cyan color palette with glassmorphism effects
- 📱 **Fully Responsive** — Mobile-first layout with hamburger navigation
- ⚡ **Smooth Animations** — Scroll-reveal effects, animated skill bars, floating cards
- 🧩 **Sections Included:**
  - Hero — Name, role, stats, floating skill tags
  - About / Services — Web Dev, Machine Learning, SQA
  - Work Experience — Animated timeline
  - Featured Projects — 6 project cards
  - My Expertise — Skill progress bars
  - FAQ — Accordion-style Q&A
  - Contact — Form + email, phone, socials
- 📄 **Downloadable Resume** — One-click CV download button

## 🚀 Getting Started

No build tools or dependencies required. Simply open the project locally:

```bash
# Clone the repository
git clone https://github.com/your-username/portfolio.git

# Navigate into the folder
cd portfolio

# Open in browser
start index.html       # Windows
open index.html        # macOS
xdg-open index.html    # Linux
```

Or just **double-click** `index.html` to open it in your browser.
